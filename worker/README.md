# خادم التنبيهات — تشغيل لمرة واحدة (مجاني، ١٠ دقائق)

بدونه تعمل التنبيهات **والتطبيق مفتوح أو مصغّر فقط**.
معه تصلك على **الآيفون واللابتوب حتى والتطبيق مغلق**: تذكير المهمة في وقتها، وتذكير ثانٍ بعد نصف ساعة إن لم تُنجز، وخطة الصباح، وإغلاق اليوم، ومواعيد متابعة المُسندين.

**التكلفة:** صفر. خطة Cloudflare المجانية تكفي بكثير: الخادم يعمل مرة كل دقيقة (١٤٤٠ مرة يوميًا من أصل ١٠٠ ألف مسموحة).

**الأمان:** الخادم لا يرى إلا عناوين المهام التي لها تذكير ونصوص التنبيه. كل طلب يُتحقق فيه من رمز دخولك في Firebase، فلا أحد غيرك يستطيع جدولة تنبيهات لك أو قراءتها. ولا توجد أسرار تنسخها يدويًا: مفاتيح التنبيهات تُنشأ تلقائيًا أول مرة.

## الخطوات (من لوحة Cloudflare، بلا أي برامج)

1. **قاعدة البيانات:** ادخل [dash.cloudflare.com](https://dash.cloudflare.com)، ثم **Storage & databases** ← **D1 SQL database** ← **Create database**. سمّها `command-center` ← **Create**.

2. **الخادم:** **Workers & Pages** ← **Create** ← **Create Worker** (أو Start with Hello World). سمّه `cc-push` ← **Deploy**.

3. **الكود:** في صفحة الـWorker اضغط **Edit code**. احذف كل ما في المحرّر، والصق محتوى الملف `worker/worker.js` من هذا المستودع كاملًا ← **Deploy**.

4. **ربط قاعدة البيانات:** صفحة الـWorker ← **Settings** ← **Bindings** ← **Add** ← **D1 database**.
   - Variable name: `DB` (بالحروف الكبيرة تمامًا)
   - D1 database: `command-center`
   ← **Add Binding** (أو Deploy).

4ب. **الذكاء الاصطناعي (للإدخال الصوتي ومحضر الاجتماع):** نفس الصفحة ← **Bindings** ← **Add** ← **Workers AI** ← Variable name: `AI` ← **Add Binding**. مجاني ضمن ١٠٬٠٠٠ neuron يوميًا (نحو ساعتين ونصف تفريغ صوتي). بدونه تعمل التنبيهات فقط.

5. **التشغيل كل دقيقة:** **Settings** ← **Trigger events** (أو Triggers) ← **Add** ← **Cron Trigger** ← اكتب:
   ```
   * * * * *
   ```
   ← **Add**.

6. **تأكد أنه يعمل:** افتح رابط الـWorker (مثل `https://cc-push.اسمك.workers.dev`). يجب أن ترى:
   ```
   {"ok":true,"service":"command-center-push","ai":true}
   ```
   ثم افتح نفس الرابط مضافًا إليه `/vapid`. يجب أن يظهر مفتاح طويل (`publicKey`).

7. **اربط التطبيق بالخادم:** أرسل الرابط لـClaude ليضعه في `js/config.js`، أو ضعه بنفسك:
   ```js
   export const pushConfig = { url: 'https://cc-push.اسمك.workers.dev' };
   ```
   ثم commit + push. يصل التحديث للأجهزة تلقائيًا.

8. **على كل جهاز:** افتح التطبيق ← **الإعدادات** ← **التنبيهات** ← **فعّل التنبيهات على هذا الجهاز** ← اسمح. ثم اضغط **أرسل تنبيهًا تجريبيًا**.

## الآيفون: شروط Apple

- iOS **16.4 أو أحدث**.
- التطبيق **مضاف إلى الشاشة الرئيسية** ويُفتح من أيقونته (Safari: مشاركة ← إضافة إلى الشاشة الرئيسية).
- الإذن يُطلب من داخل التطبيق المضاف، لا من Safari.
- أزرار «ابدأ الآن / أجّل» تظهر على ويندوز وأندرويد. على الآيفون اضغط التنبيه نفسه: يفتح التطبيق على «لحظة القرار» وفيها نفس الخيارات.

## إن لم يصل التنبيه

| العرض | السبب الأرجح |
|---|---|
| زر التفعيل غير ظاهر على الآيفون | التطبيق مفتوح من Safari لا من أيقونة الشاشة الرئيسية |
| «تعذّر ربط خادم التنبيهات» | الرابط في `config.js` غير صحيح، أو لم تسجّل الدخول للمزامنة |
| الرابط يعرض `D1 binding "DB" is missing` | الخطوة ٤: اسم المتغير يجب أن يكون `DB` |
| التجريبي يصل والتذكيرات لا | الخطوة ٥: لم يُضف Cron Trigger |
| يصل متأخرًا دقيقة أو اثنتين | طبيعي: الخادم يفحص كل دقيقة |

## ما يحفظه الخادم

- `subs`: أجهزتك المشتركة (رابط الاشتراك الذي يعطيه المتصفح، ونوع الجهاز). لا يقبل إلا خدمات التنبيهات المعروفة (Apple وGoogle وMozilla وMicrosoft).
- `schedules`: صف واحد لك يحمل التنبيهات القادمة (العنوان، النص، الوقت). يُستبدل كاملًا مع كل تغيير في مهامك.
- `sent`: ما أُرسل فعلًا، حتى لا يتكرر. يُحذف بعد ٨ أيام.
- `kv` و`hits`: مفتاح التنبيهات الخاص بالخادم، وحدّ بسيط لزر التنبيه التجريبي، وعدّاد يومي لطلبات الذكاء الاصطناعي لكل مستخدم.
- **الصوت ونصوص الاجتماعات لا تُحفظ على الخادم**: تُفرَّغ وتُحلَّل وتُعاد للتطبيق فورًا. المحضر بعد مراجعتك يُحفظ في حسابك على Firebase فقط.

**إيقاف التنبيهات أو تسجيل الخروج** يحذف اشتراك ذلك الجهاز، وإن لم يبقَ لك جهاز يُحذف جدولك من الخادم أيضًا.

**ضمن حدود الخطة المجانية:** يرسل الخادم حتى ٤ تنبيهات في الدقيقة، والباقي في الدقيقة التالية. والتنبيه لا يُسجَّل مُرسلًا إلا بعد نجاح إرساله، فلا يضيع إن تعطّل تشغيلٌ ما.
