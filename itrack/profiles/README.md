# ملفات الجهات (Profiles)

كل ملف هنا = هيكل جهة واحدة لبناء بيانات العرض. **لا يختلط ملف بآخر.**

| الملف | الاستخدام |
|---|---|
| `asas.json` | نسخة أسس الأمانة فقط (٧ إدارات، ١٣ قسمًا). للعرض على إدارتهم. |
| `generic.json` | نسخة محايدة تُعرض على أي شركة أخرى. بلا أي اسم أو هيكل من أسس. |

```bash
node itrack/tools/seed-demo.mjs http://localhost:8080 --reports --profile=asas
node itrack/tools/seed-demo.mjs http://localhost:8080 --reports --profile=generic   # الافتراضي
```

- كود التطبيق نفسه (الخادم والواجهة) محايد؛ الفرق كله في هذه الملفات وفي القاعدة التي تُبنى عليها.
- **قاعدة منفصلة لكل جهة**: شغّل خادمًا بـ`DATA_DIR` مختلف لكل عرض، ولا تبنِ النسختين على قاعدة واحدة.
- لجهة جديدة: انسخ `generic.json` وعدّل الهيكل.
