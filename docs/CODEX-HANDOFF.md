# تسليم لكودكس: تطوير UI/UX لـ «مركز القيادة»

تطبيق مهام وأولويات شخصي (PWA عربي RTL) لمدير إداري ولوجستي. **ليس تطبيقًا للجميع**: مستخدم واحد مشغول، يتشتت بسهولة، ويفتح التطبيق من اللابتوب والآيفون عدة مرات يوميًا.

## مبدأ التصميم الحاكم (من طلب المستخدم)
1. **لا زحمة، خاصة عند التعمق في إضافة المهام.** أي إضافة تُقاس بسؤال: هل تزيد ما يراه المستخدم لحظة فتح الشاشة؟ إن نعم فلتُخفَ خلف «التفاصيل».
2. **السرعة قبل الجمال.** فتح المهمة والتنقل فوريان (الآن ≈٧٠ms مع ٤٠٠ مهمة). لا تضف ما يبطئهما.
3. **التقاط الفكرة بأقل احتكاك**: زر الصوت كبير في منطقة الإبهام، يبدأ فورًا ويتوقف عند الصمت.
4. **المسيرة مرئية**: هرم فرانكلين (قيم ← أهداف بعيدة ← قريبة ← اليوم) يربط كل مهمة بغاية.
5. العربية أولًا، بلا تزيين زائد. الذهبي للتفاصيل الدقيقة فقط.

## ما بُني وأين
| الميزة | الملفات |
|---|---|
| شاشة المهمة الهادئة (`pane`) + زر «التفاصيل» (`ui.paneMore`) | `js/views.js` |
| بومودورو (٢٥/٥/١٥، `task.pomos`) ووضع التركيز | `js/app.js` (`startFocus`, `tick`, `runTimer`), `focusView` في `views.js` |
| هرم الأهداف (حد ٥ قيم، ٣ أهداف بعيدة، ٣ خطوات مفتوحة لكل هدف، الزائد `parked`) | `js/pyramid.js`, `js/model.js` (`parkIfFull`, `goalLevel`…) |
| زر الصوت: الجوال `.mic-fab` وسط الأسفل، اللابتوب `.mic-side` + اختصار `V` | `index.html`, `styles.css` (آخر الملف), `js/app.js` (`case 'voice'`) |
| التقاط الصوت: يطلب الميكروفون في لحظة اللمس، تحميل مسبق لـ`ai.js`، إيقاف تلقائي بعد ١٫٦ث صمت | `js/app.js`, `js/ai.js` (`watchSilence`, `Recorder.start(streamP)`) |
| ثيم «طين وبحر» (`data-theme="dar"`) + تنفيذي + أخضر | `styles.css` (متغيرات OKLCH/hex في `:root` ثم `:root[data-theme=…]`) |

## قيود تقنية ثابتة (لا تكسرها)
- بلا بناء ولا حزم: JS modules خام، CSS واحد. الأيقونات sprite في `index.html` (`I('name','i|d|f')`).
- **ارفع `VERSION` في `sw.js` عند أي تعديل** وإلا لن يصل لأجهزته.
- الكتابة patches على مستوى الحقل (merge). أي استيراد يمر عبر `sanitize()` في `app.js`.
- الألوان تجتاز WCAG AA في الفاتح والداكن (افحص بـ `tests/pyr_axe.js`). أي لون جديد يُفحص.
- لا تكرر ما يوفره المتصفح/Firebase. مجاني 100%.

## أفكار UI/UX المطلوب من كودكس استكشافها (بالترتيب)
1. **إدخال أول مرة**: شاشة بداية من ٣ خطوات (قيمك ← هدف بعيد ← أول خطوة) بدل الهرم الفارغ.
2. **شاشة اليوم**: أن تُظهر الأولويات الثلاث + خطوة واحدة تالية فقط؛ تحقق من أنها لا تزدحم بعد ٣٠ مهمة.
3. **وضع التركيز**: شاشة كاملة أهدأ، صوت/اهتزاز ناعم عند نهاية الجلسة، عرض عدد الجلسات اليوم.
4. **زر الصوت**: حالة التسجيل (موجة/مستوى)، إلغاء بالسحب، ومراجعة أسرع (تأكيد بنقرة واحدة عند الثقة العالية).
5. **الجوال**: قياس الوصول بالإبهام لكل الأزرار الأساسية على شاشة ٣٩٠×٨٤٤ و٣٢٠ عرض.
6. حركة دقيقة (≤٢٠٠ms) تحترم `prefers-reduced-motion`.

## ما لم يُختبر (كن صريحًا في تقاريرك)
- لم يُجرَّب على أجهزة المستخدم الحقيقية ولا بحسابه. جودة تفريغ العربية/اللهجة اليمنية الفعلية غير مقيسة.
- الخادم (Cloudflare Worker) ينشر التنبيهات؛ ربط Workers AI يحتاج تأكيدًا.

## كيف تعمل محليًا
`python3 -m http.server 8790` ثم افتح `http://localhost:8790`. الاختبارات في `tests/README.md`.
